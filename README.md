# 🧾 CV Builder

A minimalist, fast, and printable CV builder built with **React + Vite + Tailwind CSS**.
Create, edit, and preview your resume in real time — then print it with a clean layout.

---

## ✨ Features

* 📄 **Live Preview** — See your CV update instantly as you type
* 🧩 **Modular Sections**

  * Personal Information
  * Education
  * Experience
  * Skills
* ➕ **Dynamic Editing**

  * Add, edit, and delete entries
* 🎨 **Minimal UI** — Clean, distraction-free editing experience
* 🖨️ **Print-Ready Layout** — Optimized A4 CV output
* 📦 **Sample Data Loader** — Quickly test with pre-filled content

---

## 🛠️ Tech Stack

* **React 19**
* **Vite**
* **Tailwind CSS**
* **React Icons**

---

## 🚀 Build

### 1. Clone the repo

```bash
git clone https://github.com/your-username/cv-builder.git
cd cv-builder
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview production build

```bash
npm run preview
```

---


## 🎯 Usage

1. Fill in your personal details
2. Add education and experience entries
3. List your skills
4. Click **Print** to generate your CV

---


## ⚠️ Notes

* This project is **frontend-only** (no backend or persistence)
* Data will reset on refresh
* Optimized primarily for **desktop + print**
